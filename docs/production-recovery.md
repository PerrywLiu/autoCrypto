## 行为

- 主循环分别处理行情获取失败和程序/交易异常。单次行情失败不锁死交易，失败期间不计算新信号；连续行情失败达到 `max_api_errors` 后标记 `market_data_unavailable`。取得有效、及时且无重复时间戳的 K 线后解除该行情暂停。交易所模式还须通过账户/保护单对账。
- 行情成功不会解除订单失败、状态损坏、持仓不一致或保护单缺失等暂停。
- 平仓保存 `last_trade_candle_ts`，按 K 线时间计算经过的周期；重启和重新加载历史数组不会延长冷却。旧版状态从最近平仓记录恢复时间。缺少可恢复时间的旧状态暂停并显示原因，不擅自清除冷却。当前 jp 的那笔旧交易迁移已在本地验证。
- 纸面模式跳过需要鉴权的持仓查询和杠杆设置。
- `outputs/production_health.json` 每次轮询写入一次，独立于成交状态。包含进程状态、行情和账户错误计数、暂停原因、最后成功行情、最后收盘 K 线、剩余冷却和最近信号判断。心跳超过 180 秒或缺失时，看板显示过期；看板读取失败也不能保留正常标签。
- 新发生的模拟核心现货买卖保存于状态文件的 `core_trade_log`，记录方向、时间、价格、数量、名义金额和手续费。持仓快照与成交列表明确区分。旧版缺少逐笔价格/数量的记录不补造。
- 状态和心跳使用临时文件后原子替换，减少看板读到部分 JSON 的机会。状态仍兼容 version 1；新增字段为可选兼容扩展。
